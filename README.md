# ⚡ NEON MATCH

**A neon memory card puzzle game. 20 levels. Works offline. Installable as app.**

[![Play Now](https://img.shields.io/badge/▶_PLAY_NOW-2ee6ff?style=for-the-badge&labelColor=05070f)](https://sakibsheikho69252-netizen.github.io/neon-match/)

## 🎮 What is it?

A neon-styled memory card matching game. Flip cards, find pairs, complete 20 levels with increasing difficulty.

## ✨ Features

- 20 levels across 4 difficulty tiers
- Neon glass design with glow effects
- Web Audio API generated sounds
- Vibration feedback
- Progress saved locally
- Works offline
- Installable as a mobile app (PWA)

## 🕹️ How to Play

1. Tap a card to flip it
2. Find two matching symbols
3. Match all pairs to complete the level
4. Fewer moves + faster time = 3 stars

## 🌐 Play Online

👉 **https://sakibsheikho69252-netizen.github.io/neon-match/**

## 📱 Install as App

1. Open the game in Chrome
2. Tap menu → "Add to Home Screen"
3. Game installs as a native app

## 🛠️ Tech

Vanilla JavaScript, Web Audio API, localStorage, PWA.
